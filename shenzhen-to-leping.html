这次为什么大胆绕

赣州古城和景德镇对爸爸都不新鲜，就不拿“顺路但平淡”的城市凑数。这条线把重点换成潮州工夫茶、卤鹅、粿品，泉州开元寺、蟳埔和闽南面线糊；每站都有适合独自进入的街巷、博物馆和小吃。

潮州：古城 + 工夫茶泉州：海丝遗产 + 闽南小吃南昌：滕王阁 + 赣鄱菜自然风光：只作调味

一个人也成立

不安排游湖、拼船和需要凑人数的项目。路线围绕可以独自完成的步行、看展、逛庙、喝茶、吃小份展开。游泳没有合适的官方自然泳点就放弃，不为了“有水”而安排水上活动。

优先级：特色美食 ＞ 有辨识度的景点 ＞ 老街散步 ＞ 自然风光 ＞ 游泳。
DAY01深圳 → 潮州

到潮州，先让味觉醒过来

深圳北 → 潮汕站　高铁约 2.5–3 h；潮汕站 → 潮州古城　公交 / 网约车约 30–45 min

潮州古城：牌坊街、广济桥、开元寺

抵达后住古城边，下午步行逛牌坊街、广济桥和开元寺。晚餐不点大桌：潮州卤鹅、牛肉火锅、粿品、蚝烙，按小份一路吃。

卤鹅 · 牛肉火锅 · 蚝烙 · 粿品

夜里：喝一盏工夫茶

找一家能单人落座的茶馆或老厝茶空间，体验潮州工夫茶；这比安排一个人去游湖更有地方性，也更适合独行。

DAY02潮州 → 泉州

从工夫茶到海丝古城

潮汕站 / 潮州站 → 泉州　高铁约 2–3 h；泉州站 → 古城　公交 / 网约车

泉州古城：开元寺、西街、清净寺

下午逛开元寺双塔、西街、钟楼和清净寺，路线密集，适合一个人走。晚餐吃面线糊、牛肉羹、姜母鸭、土笋冻或烧肉粽。

海丝遗产 · 闽南小吃 · 老城

晚上：看一场南音或逛西街

优先查当日南音演出；没有演出就沿西街慢逛，找小店吃一轮。泉州的“特色”在街巷和信仰混在日常里，不需要专门追自然景观。

DAY03泉州慢逛

把泉州的“神、人、吃”走成一条线

全天古城步行 + 公交；蟳埔村可作为半日备选

上午：天后宫、德济门遗址、关岳庙

一条线看泉州的海洋贸易、民间信仰与城市生活；中午继续吃小份，不安排需要多人共享的菜。

海丝遗产 · 闽南信仰

下午：蟳埔村，或者留在古城

想看海边生活，可去蟳埔村看簪花围与蚵壳厝；如果不想折腾，就留在古城逛书店、喝茶、继续吃。自然风光只是顺带，不把它当主菜。

DAY04泉州 → 南昌 → 乐平

最后一站放在南昌，吃点热闹的再回家

泉州 → 南昌　高铁约 4–5 h；南昌西 / 南昌 → 乐平　铁路约 1.5–2.5 h（按 12306 车次衔接）

中转时间够长：滕王阁或八一馆二选一

如果车次衔接允许，在南昌留 3–5 小时：滕王阁适合第一次来南昌，八一馆更适合快速看城市历史。晚餐可吃瓦罐汤、拌粉，再回乐平。

南昌拌粉 · 瓦罐汤 · 城市记忆

如果只有 3 天

压缩为：Day 1 深圳 → 潮州，Day 2 潮州 → 泉州，Day 3 泉州 → 南昌 → 乐平。泉州只留古城主线，放弃蟳埔村。
