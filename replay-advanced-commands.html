回放高级指令

把重复操作组织成可控的时间轴、条件分支与 OCR 驱动流程。

00

能力总览

时间speed · sleep · skip条件doif start / stopOCRreplay · click区域readerlist / add循环count / -1
01

时间控制

control / speed

动态调整回放速度

1.0 正常；大于 1 加速，小于 1 减速。

{
  "type": "control",
  "action": "speed",
  "value": 1.5
}
sleep

显式等待

sleep_time 单位为毫秒，realSleep 默认开启。

{
  "type": "sleep",
  "sleep_time": 2000,
  "realSleep": true
}
skip / time

跳过或修正时间轴

正数让后续动作提前，负数抵消时间偏移。

{
  "type": "skip",
  "action": "time",
  "skip_time": 2900
}
02

条件控制

doif / start

开始条件区间

按逗号分隔需要执行的回放轮次。

{
  "type": "doif",
  "action": "start",
  "key": "replay_count",
  "value": "1,3"
}
doif / stop

结束条件区间

关闭当前条件区间；目前不支持嵌套。

{
  "type": "doif",
  "action": "stop"
}
03

OCR 智能动作

doif / replay

命中文字后启动子回放

{
  "type": "doif",
  "action": "replay",
  "path": "继续.json",
  "key": "vm_reader",
  "value": "继续",
  "macth_rule": "or",
  "count": 1,
  "reader_timer": 1000,
  "priority": 700
}
doif / click

命中文字后自动点击

{
  "type": "doif",
  "action": "click",
  "key": "vm_reader",
  "value": "确认",
  "macth_rule": "or",
  "reader_timer": 1000
}
macth_rule / or

任一文字命中

{ "value": "确认,继续,返回", "macth_rule": "or" }
macth_rule / and

全部文字命中

{ "value": "匹配完成,确认进入", "macth_rule": "and" }
字段作用
path子回放文件名
keyOCR 通常为 vm_reader
value目标文字，逗号分隔
reader_timer识别间隔（毫秒）
priority规则优先级
support_msg_in子回放期间是否继续接收指令
04

OCR 区域控制

readerlist / add

动态更新 OCR 区域

x、y、w、h 按相同下标组成一个区域。

{
  "type": "readerlist",
  "action": "add",
  "parent_x": 2,
  "parent_y": 3,
  "x": [0, 7],
  "y": [0, 309],
  "w": [543, 547],
  "h": [101, 102],
  "cleanother": true
}
05

循环控制

count

指定回放次数

{ "file": "测试.json", "count": 5 }
count / -1

无限循环

-1 持续循环，0 按一次处理。

{ "file": "测试.json", "count": -1 }
06

限制与注意事项

条件指令不支持嵌套；OCR 使用包含匹配；无限循环可能被手动停止、连续 3 次 ESC、运行异常或定时停止时间终止。
