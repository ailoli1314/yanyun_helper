这次为什么绕湘西

你点名想去张家界，那就不凑别的"顺路城市"了。前半程把武陵源的石英砂岩峰林一次看够：袁家界的悬浮山、天子山的云海、金鞭溪的峡谷步道；后半程回程在长沙停留一夜，太平街的夜宵和一杯茶颜悦色，把山里的清冷用一个热闹的城市收尾，再回乐平。

张家界：森林公园 + 天门山长沙：橘子洲 + 太平街夜宵自然风光这次是主菜

一个人也成立

景区索道、百龙天梯、环保车都是单人友好，不用凑人；长沙部分全是步行+地铁。这条线以山为主，不安排游泳，也不安排游湖、拼船类项目。

国庆提示：张家界门票、天门山分时段票、索道都必须提前在官方渠道预约，出发前 3–7 天订好。
DAY01深圳 → 张家界

高铁进山，傍晚先吃一顿三下锅

深圳北 → 张家界西　高铁约 5h（多为直达车，少量需换乘）；西站 → 市区/武陵源　公交或网约车

下午抵达，休整 + 明日进山预告

住市区（天门山索道下站附近）或直接住武陵源，二选一：想第二天赶早就住武陵源，想吃得好就住市区。傍晚去南门口美食街，三下锅、土家腊肉、合渣按小份点。

三下锅 · 腊肉 · 合渣

晚上：检查预约，早睡

确认明天森林公园门票、环保车和百龙天梯/索道的预约时段；山里行程消耗大，今晚不熬夜。

DAY02张家界国家森林公园

袁家界、天子山、金鞭溪，一整天

景区环保车串联各点；百龙天梯上山 + 索道下山最省体力，步行金鞭溪约 2.5h 平路

上午：袁家界「悬浮山」+ 天子山

袁家界是《阿凡达》哈利路亚山的原型观景台，迷魂台、天下第一桥都在这一线；天子山看峰林全景，运气好有云海。人多就走得慢一点，单人反而灵活。

阿凡达原型 · 峰林 · 云海

下午：金鞭溪慢走，回市区吃第二轮

从水绕四门方向进金鞭溪，全程平缓步道，溪边走 2–2.5 小时不赶时间。出山后回市区，换个店再吃一顿三下锅或岩耳炖土鸡。

DAY03天门山 → 长沙

上午穿天门洞，下午去长沙吃夜宵

天门山索道上山（分时段票）；张家界西 → 长沙南　城际/高铁约 3–4h，部分直达、部分需换乘，以 12306 为准

上午：天门山——玻璃栈道 + 天门洞

索道直达山顶，走玻璃栈道（恐高可以走旁边普通道）、鬼谷栈道；下山到天门洞爬 999 级上天梯。注意天门山票分 A/B/C 线和时段，务必按预约时段到。

玻璃栈道 · 天门洞 · 999 级天梯

晚上：长沙的烟火气

傍晚到长沙南，地铁进城。太平街、坡子街夜宵：臭豆腐、糖油粑粑、口味虾（小份），排队买杯茶颜悦色，一个人边走边吃刚好。

DAY04长沙 → 南昌 → 乐平

橘子洲看一眼湘江，再回乐平

长沙南 → 南昌（西/东）　高铁约 1.5h；南昌东 → 乐平北　昌景黄高铁约 40min；换乘按 12306 车次衔接

上午：橘子洲头（或省博物馆）

地铁 2 号线直达橘子洲，走到青年毛泽东雕像看湘江两岸；如果更想看文物，改去湖南省博物馆看马王堆（需提前预约，周一闭馆）。中午吃火宫殿或文和友小份拼桌。

橘子洲 · 马王堆（二选一）· 火宫殿

下午：回程——长沙 → 南昌 → 乐平

下午从长沙南出发，南昌换乘昌景黄高铁到乐平北；乐平北到市区打车或公交都很近。全程含换乘约 3–4h，到家正好吃晚饭。

PLANB3 天压缩版

如果只有 3 天

Day 1 深圳 → 张家界 · Day 2 森林公园 · Day 3 天门山 + 全天回程

压缩方案：Day 1 住武陵源；Day 2 只走袁家界 + 金鞭溪精华线（放弃天子山）；Day 3 上午天门山，中午下山直接张家界西 → 长沙南 → 南昌 → 乐平，夜车到家。放弃长沙夜宵和橘子洲——山和城市只能选一头。
